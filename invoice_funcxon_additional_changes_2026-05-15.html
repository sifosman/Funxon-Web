Original Proposal Scope Summary

The original proposal was for a React Native mobile app with Supabase backend/storage, vendor discovery, Google Maps, filters/sorting, vendor profile tabs, plan limits, quote-to-booking flow, payment gateway integration, WhatsApp support link, push/email notifications, admin approvals/reviews, analytics/crash monitoring and App Store/Play Store submission support.

The proposal also allowed for 2 UAT rounds and stated that changes beyond MVP are quoted separately. The items below are therefore treated as additional change-request work because they add new screens, redesign existing flows, alter previously built workflows, or require additional testing/stabilisation after late-stage changes.

Executive Summary of Additional Work

  • Home and discovery redesign: New banner wording, featured venue/vendor carousels, province cards, discover filtering, guest-access rules and latest home “Get Listed” carousel change.
  • Listers acquisition and management: New listers portal, CTA sections, reviews block, blog integration, footer/header updates, lister portfolio management and routing changes.
  • Application/subscription flow rework: Changed application forms, package display, checkout placement, direct navigation to portfolio management, document/field removals and validation updates.
  • Catalogue and quote expansion: Catalogue screens, catalogue view/form updates, quote edit planning, tour count/notes requirements and quote communication considerations.
  • Profile/account/planner refinements: Account screen changes, deletion option, profile action changes, WhatsApp/email/tour contact actions and planner requested changes.
  • Stabilisation: Fixes for navigation, application state, upload handling, maps, TypeScript, forms and regression issues arising from late-stage flow changes.
